# Overview

I created an expense tracker web app that runs on a local test server. The user can add expenses, display the complete expense list, filter expenses by category, calculate totals, and delete an expense using its ID. Each expense has an ID, description, category, and amount.

To run the app, open a terminal in the project folder and use `npm install` the first time. Then use `npm start` to start the test server. Open `http://localhost:3000` in a web browser to see the home page.

I wrote this software to learn how a web framework creates dynamic pages. I also wanted to practice Express routes, EJS templates, form processing, validation, and sending JavaScript data to HTML pages.

# Web Pages

The home page displays the number of expenses, the total amount, and totals organized by category. This information is created dynamically from the current expense list. The navigation menu connects the home page to the expense list and add expense pages.

The expense list page displays every expense in a table. The user can select a category to filter the list, see the total for the displayed expenses, and delete an expense. The table, categories, and total are generated by the Express route and displayed with EJS.

The add expense page contains a form for the description, category, and amount. When the user submits valid information, the app adds the expense and redirects to the expense list. If the information is invalid, the same page displays clear error messages and keeps the values that the user entered.

# Development Environment

I used Visual Studio Code to write the project and PowerShell to run the commands. I used Node.js to execute the server, npm to install the project packages, and Git for version control.

The web app was written in JavaScript. It uses Express to process routes and requests, EJS to generate HTML pages with JavaScript data, and CSS to style the pages. The expenses are stored in memory while the server is running.
